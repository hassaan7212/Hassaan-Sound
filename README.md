# HASSAAN SOUND & MEDIA PRODUCTION

A responsive company website built around the green/white color palette of the supplied logo.

## Files
- `index.html` — website
- `style.css` — responsive styling
- `script.js` — mobile navigation and demo contact form
- `assets/` — supplied logo and media

## Zoho Recruit
In `index.html`, find `YOUR_ZOHO_RECRUIT_FORM_URL` and replace it with the published Zoho Recruit job-opening/application form URL.

The Careers section is intentionally included so the site can be used as a realistic front-end for testing your Zoho Recruit → n8n → AI screening workflow.
